# SANTIK NETWORK — установка на хостинг с панелью

Версия: **Paper 1.21.4, Java 21** (в `pom.xml` зафиксирован paper-api 1.21.4-R0.1-SNAPSHOT).
Всё работает от одного плагина **SantikCore** — других плагинов ставить не нужно
(права, лобби-защита, экономика, аукцион, дома, TPA, капча — внутри).

## Шаг 1. Получить SantikCore.jar (без программирования)
1. Зарегистрируйся на https://github.com и создай пустой репозиторий.
2. Загрузи в него всё содержимое папки `santik-server` (кнопка «Add file → Upload files»).
3. Открой вкладку **Actions** → «Build SantikCore» → **Run workflow**.
4. Когда появится зелёная галочка, скачай результат (**Artifacts → SantikCore**) и распакуй — внутри `SantikCore.jar`.
   Если сборка красная — открой её, скопируй текст ошибки и пришли мне.

## Шаг 2. Хостинг
1. В панели выбери ядро **Paper**, версия **1.21.4**, Java **21**.
2. Первый запуск → прими EULA (https://aka.ms/MinecraftEULA) → останови сервер.
3. В `server.properties` выставь значения из `server/server.properties` (главное `online-mode=true`).
4. Загрузи `SantikCore.jar` в папку `plugins/`.
5. Запусти сервер. При первом старте плагин сам создаст миры и построит лобби
   (в консоли «Строю площадку…»; анархия-плац строится 5–30 секунд — это нормально).
6. Зайди в игру и пройди капчу → `/reg <пароль> <повтор>`. Если твой ник `reuzc`,
   ты автоматически закрепишься владельцем (UUID сохранится в `plugins/SantikCore/config.yml`).

Остальное — в `OWNER_GUIDE.md`. Что проверено и что нет — в `docs/STATUS.md` и `docs/TEST_CHECKLIST.md`.
